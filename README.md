# IST ↔ UTC Aviation Converter — Picker Edition
Use the date picker and native 24-hour time picker instead of typing timestamps.
Features: IST/UTC-Zulu, live clocks, seconds, automatic date rollover, copy result, dark mode, current time, swap direction, offline PWA.
Host index.html, manifest.json and sw.js over HTTPS (GitHub Pages works), then open in Chrome and Add to Home screen.
